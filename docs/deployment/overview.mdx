# Deployment Overview

## Components

- Frontend: Vite build output in `frontend/dist`.
- Backend: Node.js Express API exported from `backend/src/server.js`.
- Database: PostgreSQL.
- Docs: Mintlify.

## Required environment

- Backend database URL.
- Auth secrets.
- Supabase configuration when used.
- Frontend API URL.
- Backend CORS client URL.

## Vercel Demo Deployment

Deploy the demo as two Vercel projects from the same repository.

### Frontend project

Use these Vercel settings:

```text
Framework Preset: Vite
Root Directory: frontend
Build Command: npm run build
Output Directory: dist
Install Command: npm install
```

Set frontend environment variables:

```text
VITE_API_URL=https://<backend-vercel-project>.vercel.app
```

`frontend/vercel.json` rewrites non-API routes to `index.html` so direct navigation and refreshes work in the Vite SPA.

### Backend project

Use these Vercel settings:

```text
Root Directory: backend
Install Command: npm install
Build Command: npm run prisma:generate
Output Directory: leave empty
```

Set backend environment variables:

```text
DATABASE_URL=<postgres-or-supabase-pooler-url>
JWT_SECRET=<strong-random-secret>
CLIENT_URL=https://<frontend-vercel-project>.vercel.app
FRONTEND_URL=https://<frontend-vercel-project>.vercel.app
BACKEND_URL=https://<backend-vercel-project>.vercel.app
SUPABASE_URL=https://<supabase-project>.supabase.co
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_USER=<shared-gmail-address>
SMTP_APP_PASSWORD=<google-app-password>
EMAIL_FROM=Pet Service <shared-gmail-address>
EMAIL_REMINDER_INTERVAL_MINUTES=60
SUPABASE_KEY=<supabase-anon-key>
SUPABASE_SERVICE_ROLE_KEY=<supabase-service-role-key>
```

`CLIENT_URL` and `FRONTEND_URL` may contain comma-separated origins when both production and preview domains need API access.

For serverless deployments, schedule `npm run email:reminders` with the platform cron instead of relying on the in-process interval.

After deployment, verify:

```text
https://<backend-vercel-project>.vercel.app/api/health
https://<frontend-vercel-project>.vercel.app
```

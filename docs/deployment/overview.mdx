# Deployment Overview

## Components

- Frontend: Vite build output.
- Backend: Node.js Express service.
- Database: PostgreSQL.
- Docs: Mintlify.

## Required environment

- Backend database URL.
- Auth secrets.
- Supabase configuration when used.
- Frontend API URL.
- Backend CORS client URL.

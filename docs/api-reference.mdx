## Base URL

Local backend:

```text
http://localhost:5050
```

Frontend dev server proxies `/api` to the backend.

## Health

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/health` | Checks backend, Supabase, and Prisma configuration status. |

## Auth

- `POST /api/auth/forgot-password/request` creates a short-lived reset OTP.
- `POST /api/auth/forgot-password/verify` verifies the OTP.
- `POST /api/auth/forgot-password/reset` verifies the OTP, updates the password hash, and invalidates existing JWT sessions.

Password reset emails are sent through Gmail SMTP when `SMTP_USER` and `SMTP_APP_PASSWORD` are configured. For local non-production testing without SMTP credentials, the request endpoint returns `devCode`.

Routes are mounted under `/api/auth`.

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/api/auth/register` | Register a user. |
| `POST` | `/api/auth/login` | Login and receive auth data. |
| `GET` | `/api/auth/me` | Get current authenticated user. |

## Admin

Routes are mounted under `/api/admin` and require an admin auth token.

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/admin/dashboard` | Get admin totals for dashboard widgets. |
| `GET` | `/api/admin/users?role=&search=` | List customers, doctors, and staff users with backend search and user-management summary for `UsersPage`. |
| `PATCH` | `/api/admin/users/:role/:id/lock` | Lock or unlock one customer, doctor, or staff account from `UsersPage`. |
| `GET` | `/api/admin/services?category=&status=&search=` | List backend-filtered service catalog rows plus category counts and service KPI summary for `ServicesPage`. |
| `POST` | `/api/admin/services` | Create one service catalog row. |
| `PATCH` | `/api/admin/services/:id` | Update one service catalog row. |
| `PATCH` | `/api/admin/services/:id/status` | Activate or deactivate one service catalog row. |
| `GET` | `/api/admin/appointments?status=&search=` | List backend-filtered appointment rows plus tab counts, service/staff options, and amount summary for `AppointmentsPage`. |
| `PATCH` | `/api/admin/appointments/:id/status` | Update one appointment status from the admin appointment drawer. |
| `GET` | `/api/admin/staff?department=&status=&search=` | List backend-filtered doctor and staff rows with staff-management summary for `StaffPage`. |
| `PATCH` | `/api/admin/staff/:id/lock` | Lock or unlock one doctor/staff account from `StaffPage`. |
| `GET` | `/api/admin/reports` | Get backend-shaped revenue, appointment, service, and staff-performance report data. |
| `GET` | `/api/admin/settings` | Get backend-shaped clinic, account, notification, payment, and security settings data. |
| `GET` | `/api/admin/email-templates` | Get persisted templates for transactional and reminder emails. |
| `PUT` | `/api/admin/email-templates` | Update email subjects, headings, and messages. |
| `POST` | `/api/admin/email-templates/test` | Send a custom test email through configured SMTP. |

Template content supports variables such as `{{petName}}`, `{{appointmentCode}}`, `{{appointmentDate}}`, `{{appointmentTime}}`, `{{diagnosis}}`, and `{{amount}}`.
| `GET` | `/api/admin/exam-context` | Get appointment, pet, history, symptom, body-system, and prescription option data for `ExamPage`. |
| `GET` | `/api/admin/doctors` | List doctor users without doctor profiles. |
| `POST` | `/api/admin/doctors/create-profile` | Create one doctor profile for a doctor user. |
| `POST` | `/api/admin/doctors/init-all` | Create missing doctor profiles for all doctor users. |

## Doctor

Routes are mounted under `/api/doctor` and require a doctor auth token.

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/doctor/profile` | Get the current doctor's profile. |
| `GET` | `/api/doctor/records` | List appointment-backed patient history for the current doctor, including pet identity for grouping records by pet. Supports `search` and `species` query filters. |
| `GET` | `/api/doctor/stats` | Get current doctor's dashboard statistics for month, week, day, and quarter views, including render-ready KPI cards. |
| `GET` | `/api/doctor/settings` | Get current doctor's settings payload, including profile, schedule rows, notification preferences, and security/session metadata. |
| `GET` | `/api/doctor/exam/:appointmentId` | Get database-backed context for `DoctorExamScreen`, including pet, owner, vaccination, visit history, and initial form data. |
| `GET` | `/api/doctor/appointments` | List current doctor's active appointments with backend-shaped portal rows, status view metadata, schedule summary counts, and header metadata. |
| `PUT` | `/api/doctor/appointments/:appointmentId/start` | Mark one current-doctor appointment as in progress. |
| `PUT` | `/api/doctor/appointments/:appointmentId/complete` | Mark one current-doctor appointment as completed. |

## Customer Notifications

Routes are mounted under `/api/customer` and require a customer auth token. Notification reads are scoped to the authenticated user.

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/customer/notifications` | List notifications for the current user with total and unread summary. |
| `PATCH` | `/api/customer/notifications/:notificationId/read` | Mark one current-user notification as read. |
| `PATCH` | `/api/customer/notifications/read-all` | Mark all current-user notifications as read. |
| `DELETE` | `/api/customer/notifications/:notificationId` | Dismiss one current-user notification. |

## Customer Appointments

Routes are mounted under `/api/customer` and require a customer auth token. Appointment reads and writes are scoped to pets owned by the current customer.

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/customer/appointment-options` | List database-backed service options for customer booking. |
| `POST` | `/api/customer/appointment-provider-options` | List providers for the requested service slot. Doctor services return doctors whose `doctor_schedules` cover the selected time and who are not already booked at that exact date/time; staff services return the staff list. |
| `GET` | `/api/customer/appointments?status=&pet=&serviceType=&page=&pageSize=` | List current customer's appointments with backend filtering, status counts, and pagination summary. |
| `POST` | `/api/customer/appointments` | Create a pending appointment for one current-customer pet and the selected provider. |
| `PATCH` | `/api/customer/appointments/:appointmentId/reschedule` | Update appointment schedule date/time when a linked doctor schedule is available. |
| `PATCH` | `/api/customer/appointments/:appointmentId/cancel` | Cancel one current-customer appointment. |

# Features Overview

## Current feature areas

- Authentication and role-based portals.
- Customer pet profile management.
- Appointments and service selection.
- Doctor examination and medical records.
- Staff operations and reporting.
- Grooming and boarding records.
- User, settings, services, and help pages.

## Feature documentation rule

When a feature changes, update this page or add a dedicated feature page and register it in `docs/docs.json`.

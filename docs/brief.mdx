# Project Brief

## Goal

Build a pet service management system that supports customer self-service and internal clinic operations.

## Primary users

- Customers manage pet profiles and appointments.
- Doctors review exams, medical records, schedules, and stats.
- Staff support appointments, grooming, boarding, reports, and service operations.
- Admins manage users, settings, services, and system data.

## Current stack

- Frontend: React 18, Vite, TypeScript, Tailwind CSS, Radix UI components.
- Backend: Express 5, Prisma, Supabase client, JWT, bcrypt.
- Database: PostgreSQL via Prisma schema and migrations.
- Documentation: Mintlify with `.mdx` pages under `/docs`.

## Documentation rule

Every functional change should update matching feature, API, database, architecture, deployment, or planning docs.

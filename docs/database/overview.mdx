# Database Overview

## Database

The project uses PostgreSQL through Prisma.

## Main domains

- Users and role profiles: users, customers, doctors, and staff.
- Pets: species, breeds, pet records, allergies, and medical notes.
- Scheduling: doctor schedules and appointments.
- Services: medical, grooming, boarding, vaccine, food, and other services.
- Clinical records: medical visits, diseases, prescriptions, and vaccinations.
- Operations: grooming records, cages, boarding, and daily updates.
- Finance and communication: invoices, invoice items, notifications, payments, and reviews.

## Migration rule

Any schema or migration change must update this page with model impact and data migration notes.

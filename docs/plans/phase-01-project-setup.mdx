# Phase 01 - Project Setup

## 1. Muc tieu phase

Xac nhan cau truc project, stack dang dung, cach chay frontend/backend, cach cau hinh moi truong va quy uoc tai lieu setup.

## 2. Pham vi cong viec

- Kiem tra cau truc thu muc hien co.
- Xac dinh frontend, backend va cac package chinh.
- Xac dinh package manager va lenh chay project.
- Kiem tra cach cau hinh bien moi truong.
- Cap nhat tai lieu setup neu can.
- Hoan thien Mintlify documentation structure.
- Cap nhat navigation via `docs.json`.
- Cap nhat root npm scripts cho docs.
- Cap nhat AI workflow instructions trong `agent.mdx`.

## 3. Checklist chi tiet

- [ ] Doc `agent.mdx`, `docs/brief.mdx`, `docs/BRD.mdx` va `docs/plans/master-plan.mdx`.
- [ ] Kiem tra `package.json` o root, frontend va backend neu co.
- [ ] Xac dinh lenh install dependency.
- [ ] Xac dinh lenh chay frontend.
- [ ] Xac dinh lenh chay backend.
- [ ] Xac dinh lenh test/lint/build neu co.
- [ ] Kiem tra file env example neu co.
- [ ] Cap nhat `docs/setup-guide.mdx` theo lenh thuc te.
- [ ] Dam bao `/docs` contains the required AI-native pages.
- [ ] Dam bao all docs pages use `.mdx`.
- [ ] Dam bao `npm run docs` starts Mintlify locally.
- [ ] Dam bao `npm run docs:check` validates the Mintlify build.
- [ ] Ghi chu cac thieu sot can lam sau.

## 4. File/thu muc du kien bi anh huong

- `agent.mdx`
- `docs/docs.json`
- `docs/setup-guide.mdx`
- `docs/CHANGELOG.mdx` neu co thay doi quan trong
- `docs/plans/master-plan.mdx`
- `package.json`
- `frontend/`
- `backend/`
- `.env.example` neu can tao o phase sau

## 5. Ket qua mong doi

Nguoi moi vao project co the biet can cai gi, chay lenh nao va project dang co nhung phan nao.

## 6. Cach test manual

- Lam theo `docs/setup-guide.mdx`.
- Chay lenh install dependency.
- Chay frontend/backend neu da co.
- Kiem tra terminal khong co loi nghiem trong.
- Mo ung dung tren browser neu frontend da san sang.
- Chay `npm run docs`.
- Chay `npm run docs:check`.

## 7. Rui ro co the gap

- Stack hien tai chua ro hoac chua dong nhat.
- Thieu file env example.
- Dependency loi thoi hoac khong cai duoc.
- Frontend/backend chua co lenh chay rieng.
- Mintlify CLI thay doi command validation theo version.

## 8. Dieu kien Done

- Da xac dinh duoc cau truc project va lenh chay co ban.
- `docs/setup-guide.mdx` phan anh dung trang thai thuc te.
- Khong hard-code secret trong tai lieu hoac source.
- Co huong dan manual test toi thieu.
- Khong con duplicate `.md`/`.mdx` cho cac docs Mintlify.

## Out of scope

- Functional frontend changes.
- Functional backend changes.
- Database schema changes.

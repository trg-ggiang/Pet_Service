# Start Session Prompt

Use this at the start of an AI coding session:

```text
Read agent.mdx first.
Then read docs/index.mdx, docs/brief.mdx, docs/BRD.mdx, docs/plans/master-plan.mdx, and the related docs for this task.
Confirm the current phase and affected docs before making changes.
Do not code functionality until the docs context is understood.
```

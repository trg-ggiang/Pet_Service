# End Session Prompt

Use this before finishing an AI coding session:

```text
Update related docs, docs/CHANGELOG.mdx, docs/plans/master-plan.mdx if phase status changed, and create or update a work log.
Update docs/docs.json if new pages were added.
Run the relevant checks and report what passed or failed.
Summarize files changed and any follow-up work.
```

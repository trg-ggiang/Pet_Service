# Pet Service

Pet Service is a web application for managing pet care operations, including accounts, pet profiles, appointments, medical visits, grooming, boarding, invoices, notifications, and reviews.

## Project areas

- Frontend: React, Vite, TypeScript, Tailwind CSS, Radix UI, and shadcn-style components.
- Backend: Node.js, Express, Prisma, Supabase integration, JWT authentication, and REST routes.
- Database: PostgreSQL through Prisma schema and migrations.
- Docs: Mintlify pages written in MDX.

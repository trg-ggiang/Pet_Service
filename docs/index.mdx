# Pet Service

Pet Service is a web application for managing pet care operations, including customer accounts, pet profiles, appointments, medical visits, grooming, boarding, invoices, notifications, and reviews.

## Documentation workflow

This documentation is designed for AI-assisted development. Before changing the project, read the relevant docs first. After each task, update the affected docs, changelog, plan, and work log.

## Project areas

- Frontend: React, Vite, TypeScript, Tailwind CSS, Radix UI, and shadcn-style components.
- Backend: Node.js, Express, Prisma, Supabase integration, JWT authentication, and REST routes.
- Database: PostgreSQL schema managed through Prisma migrations.
- Docs: Mintlify pages written in MDX.

# Phase 04 Staff Operations Testing

Phase 4 tap trung vao staff operations: staff profile, appointment confirm/check-in, grooming status, boarding daily status API va payment marking. Day la nhom flow quan trong vi staff la vai tro dieu phoi trang thai nghiep vu giua customer, doctor, grooming/boarding va thanh toan.

## 1. Pham vi

Chuc nang da kiem thu:

- Staff profile mapping: full name, initials, role label, email.
- Confirm appointment: chi cho appointment `PENDING`, gan `staff_id` hien tai.
- Confirm appointment bi chan neu appointment da gan staff khac.
- Check-in appointment: chi cho appointment `CONFIRMED`, chuyen sang `IN_PROGRESS`.
- Check-in appointment bi chan neu appointment khong o trang thai hop le.
- Grooming status: reject status khong hop le, update grooming/service/appointment sang `IN_PROGRESS`.
- Payment: invoice da `PAID` thi skip update, invoice chua paid thi mark paid va gui email xac nhan.
- Frontend staff API contract: profile, summary, pending appointments, confirm, check-in, grooming status, boarding daily status, payments va mark paid.
- Frontend staff API reject truoc khi fetch neu khong co auth session.

Ngoai pham vi Phase 4:

- Chua test boarding approve/check-in/checkout backend trong `boardingService`.
- Chua test boarding room CRUD.
- Chua test complete grooming tao invoice end-to-end.
- Chua test specialist queue/service orders.
- Chua test walk-in appointment flow.
- Chua test StaffPortal UI component bang React Testing Library.

## 3. Quy tac AAA

Tat ca test Phase 4 dung AAA.

Backend example:

```js
test("confirms a pending appointment and assigns the current staff member", async () => {
  // Arrange
  const updateQuery = createSupabaseQuery({ data: null, error: null });
  supabase.from
    .mockReturnValueOnce(createSupabaseQuery({ data: pendingAppointment, error: null }))
    .mockReturnValueOnce(updateQuery);

  // Act
  await confirmAppointment(pendingAppointment.id, staffId);

  // Assert
  expect(updateQuery.update).toHaveBeenCalledWith(
    expect.objectContaining({
      status: "CONFIRMED",
      staff_id: staffId,
    }),
  );
});
```

Frontend example:

```ts
test("updates grooming status with PATCH payload", async () => {
  // Arrange
  mockFetchJson({ ok: true, message: "ok" });

  // Act
  await staffAppointmentsService.updateGroomingStatus(900, "IN_PROGRESS");

  // Assert
  expect(fetch).toHaveBeenCalledWith(
    "http://localhost:5050/api/staff/grooming/900/status",
    expect.objectContaining({
      method: "PATCH",
      body: JSON.stringify({ status: "IN_PROGRESS" }),
    }),
  );
});
```

## 7. He thong da lam tot

- Staff profile mapping co thong tin can thiet cho portal: full name, initials, role label va contact.
- Staff confirm appointment co guard ownership: appointment da gan staff khac bi chan bang 403.
- Appointment confirm/check-in co guard theo status, tranh chuyen trang thai sai luong.
- Grooming status chi chap nhan `IN_PROGRESS` va `COMPLETED`.
- Khi grooming update sang in-progress, service va appointment cung duoc dong bo trang thai.
- Payment paid co idempotency co ban: invoice da paid thi khong update lai va khong gui email lai.
- Frontend staff service chan request khi mat auth session, tranh goi API voi session rong.
- Frontend staff API contract dung method/body cho cac thao tac quan trong.

# Phase 08E Doctor Service And Route Coverage

Phase 8E tiep tuc follow-up cua Phase 5. Muc tieu la tang coverage cho `doctorService.js` va them Supertest route coverage cho cac endpoint doctor quan trong.

## 1. Pham vi

Chuc nang da kiem thu:

- `getDoctorStats`: tinh KPI, completion rate, average rating, top services, recent patients tu appointments/reviews.
- `getDoctorSettings`: map doctor profile, group contiguous schedule slots, persist default settings khi chua co stored setting.
- `getDoctorExamContext`: build appointment, pet, vaccination, visit history va initial form cho man hinh kham.
- `listDoctorRecords`: map medical records voi diagnosis, disease rows, services va prescription items.
- `saveDoctorSettings`: merge notification/security patch vao stored settings.
- `GET /api/doctor/appointments`: route goi doctor appointment portal service.
- `GET /api/doctor/stats`, `/records`, `/exam/:appointmentId`, `/settings` va `PUT /settings`: route mapping service/body/query/user-agent.
- Doctor appointment route reject `403` khi auth context khong co `doctorId`.

Ngoai pham vi Phase 8E:

- Chua test follow-up appointment success/conflict trong route `exam-complete`.
- Chua test urgent alert backend chi tiet.
- Chua test specialist service order backend chi tiet.
- Chua test React component doctor portal/exam form.
- Chua test real Prisma/Supabase DB integration.

## 3. Quy tac AAA

Tat ca test Phase 8E theo AAA.

Example:

```js
test("GET /api/doctor/records forwards filters to doctor record service", async () => {
  // Arrange
  listDoctorRecords.mockResolvedValueOnce(records);

  // Act
  const response = await request(app)
    .get("/api/doctor/records")
    .query({ search: "milo", species: "Dog" });

  // Assert
  expect(response.status).toBe(200);
  expect(listDoctorRecords).toHaveBeenCalledWith(doctorId, {
    search: "milo",
    species: "Dog",
  });
});
```

## 7. He thong da lam tot

- Doctor stats co the tong hop appointments thanh KPI, trend, service ranking, species pie va recent patients.
- Doctor settings co default profile/schedule/notifications/security va co co che persist default preferences.
- Lich lam viec doctor duoc group tu cac slot lien tiep thanh mot window de UI hien thi gon hon.
- Exam context gom du thong tin appointment, pet, vaccination, history va initial form.
- Doctor records map duoc diagnosis, disease/system results, service va prescription items.
- Route layer truyen dung doctor id, query params, body patch va user-agent vao service layer.
- Route appointment doctor chan user doctor thieu `doctorId` bang `403`.

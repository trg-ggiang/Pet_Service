# Phase 08F Admin Routes Settings And Health Trends

Phase 8F tiep tuc follow-up cua Phase 6. Muc tieu la tang coverage cho admin backend, dac biet la route contract cua `/api/admin/*`, settings, health trends, service CRUD va tao nhan su.

## 1. Pham vi

Chuc nang da kiem thu:

- `createAdminService`: tao service moi voi payload admin va tra ve service da map.
- `updateAdminService`: update service theo display id `SV-*` va refresh list sau khi cap nhat.
- `deleteAdminService`: xoa service theo display id.
- `getAdminHealthTrends`: tong hop pet age group, species, disease va prescription trend.
- `getAdminSettings`: merge default settings voi stored settings va profile admin hien tai.
- `updateAdminSettings`: luu settings patch vao settings store.
- `updateAdminUserProfile`: cap nhat profile customer/staff tu man hinh admin.
- `createAdminStaffMember`: tao Supabase Auth Admin user va insert profile nhan su.
- `GET /api/admin/dashboard`: route goi dashboard service va tra ve payload.
- `GET /api/admin/services`: route forward `category`, `status`, `search`.
- `POST /api/admin/services`, `PATCH /services/:id`, `DELETE /services/:id`: route mapping body/id/status code.
- `GET /api/admin/health-trends`: route tra ve aggregated health trends.
- `GET /api/admin/settings`, `PUT /api/admin/settings`: route truyen authenticated admin vao settings service.
- `POST /api/admin/staff`: route tao nhan su va tra ve `201`.
- `PATCH /api/admin/staff/:id/profile`: route map staff display id vao `updateAdminUserProfile`.
- Non-admin role bi chan `403` truoc khi admin service chay.

Ngoai pham vi Phase 8F:

- Chua test admin React components.
- Chua test destructive action audit log.
- Chua test email template admin routes.
- Chua test legacy doctor profile admin routes trong `adminRoutes.js`.
- Chua test real Supabase Auth Admin integration.

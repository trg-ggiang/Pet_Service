# Phase 08A Boarding Deep Coverage

Phase 8A la phase mo rong sau strategy chinh Phase 1-7. Muc tieu la cai thien backend coverage theo rui ro, bat dau tu `boardingService.js` vi day la service lien quan booking phong, tinh tien, invoice, trang thai phong va notification.

## 1. Pham vi

Chuc nang da kiem thu:

- Room availability: reject date range khong hop le truoc khi query.
- Room availability: danh dau phong unavailable khi bi overlap hoac dang maintenance.
- Create boarding booking: validate pet ownership, cage, overlap, tao appointment, appointment service va boarding record.
- Create boarding booking: reject khi cage da co active stay overlap.
- Approve boarding booking: chuyen appointment sang `CONFIRMED` va notify customer.
- Check-in boarding: chuyen boarding `CHECKED_IN`, cage `OCCUPIED`, appointment `IN_PROGRESS`.
- Checkout boarding: reject khi invoice da `PAID`.
- Checkout boarding: tao invoice, rebuild invoice items, chuyen boarding `CHECKED_OUT`, cage `CLEANING`, appointment `COMPLETED`.
- Customer care update: owner update feeding/special note va notify staff users.
- Extend boarding stay: reject khi extension range bi overlap voi active stay khac.
- Pending/confirmed boarding lists: map room, owner, pet va nights.
- Customer boarding history: map daily updates va sort newest first.
- Extend boarding stay: success path update pickup date va notify staff.
- Boarding room CRUD: create/update va block delete khi co active boarding.
- Reschedule booked boarding: update boarding dates va appointment timestamp.

Ngoai pham vi Phase 8A:

- Chua test upload anh daily boarding qua Supabase Storage.
- Chua test route-level staff/customer boarding APIs bang Supertest.
- Chua test real DB constraint/RLS hoac concurrent booking.
- Chua test frontend boarding UI/component.

## 3. Quy tac AAA

Tat ca test Phase 8A dung AAA.

Example:

```js
test("checks out boarding with invoice items and final state updates", async () => {
  // Arrange
  const invoiceInsert = createSupabaseQuery({ data: { id: invoiceId }, error: null });
  const itemInsert = createSupabaseQuery({ data: null, error: null });

  // Act
  const result = await checkOutBoarding(boardingId, staffId, {
    foodFeePerDay: 20000,
    extraServiceFee: 50000,
  });

  // Assert
  expect(result).toEqual(expect.objectContaining({ invoiceId }));
  expect(itemInsert.insert).toHaveBeenCalledWith(
    expect.arrayContaining([
      expect.objectContaining({ source_type: "BOARDING" }),
    ]),
  );
});
```

## 7. He thong da lam tot

- Booking phong co guard ngay thang va overlap, tranh dat trung phong trong cung khoang ngay.
- Maintenance room khong duoc xem la available.
- Create booking tao day du appointment, appointment service va boarding record voi so dem/price tu cage.
- Approve/check-in dong bo status giua boarding, cage va appointment.
- Checkout co guard invoice da `PAID`, tranh sua hoa don da thu tien.
- Checkout rebuild invoice items theo room/food/extra service, giam rui ro item cu bi cong don sai.
- Customer care update co ownership guard va notify staff.
- Extend stay co overlap guard, giam rui ro phong bi dat trung trong phan ngay gia han.
- Pending/confirmed/customer boarding lists da co mapping test, giup giam rui ro sai du lieu hien thi.
- Room CRUD co guard khong xoa phong dang co active boarding.

## 8. Khuyet diem va rui ro con lai

- `boardingService.js` da vuot target 70% statement/line coverage, nhung branch coverage con thap vi chua test nhieu error/fallback branches.
- Chua test fallback migration columns, Supabase error paths va empty states day du.
- Chua co route-level tests cho staff/customer boarding endpoints.
- Chua co DB integration test de xac minh race condition khi hai booking cung phong cung luc.
- Chua test Supabase Storage upload anh boarding daily status.
- Chua test UI boarding modal/list/daily history.

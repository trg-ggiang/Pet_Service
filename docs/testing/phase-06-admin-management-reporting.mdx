# Phase 06 Admin Management And Reporting Testing

Phase 6 tap trung vao admin management va reporting: quan ly users, services, appointments, dashboard totals, reports va API contract cua frontend admin service. Day la nhom flow quan trong vi admin co quyen thay doi cau hinh van hanh, trang thai lich hen, dich vu va xem so lieu doanh thu.

## 1. Pham vi

Chuc nang da kiem thu:

- Admin users: map customer/doctor/staff tu `users` va profile tuong ung.
- Admin users summary: tong customer/doctor/staff, locked count, active doctors/staff.
- Customer spend: chi cong invoice `PAID`.
- Doctor rating: tinh diem trung binh tu ratings.
- Admin services: map category, status, bookings va revenue tu appointment services.
- Admin services: reject status khong hop le truoc khi update database.
- Admin appointments: map appointment rows, filter theo status/search, tinh amount summary.
- Admin appointment status: cancel appointment va release doctor schedule slot.
- Admin dashboard: tinh totals, status buckets, revenue va boarding room occupancy.
- Admin reports: tinh revenue, bookings, top services, appointment stats va staff performance.
- Frontend admin API contract: dashboard, users, services CRUD, appointments, staff, doctor schedules, reports, health trends va settings.

Ngoai pham vi Phase 6:

- Chua test `adminRoutes.js` bang Supertest voi role admin.
- Chua test React components: tables, filters, modals, confirmations.
- Chua test `createAdminService`, `updateAdminService`, `deleteAdminService` backend success path.
- Chua test `createAdminStaffMember`, `updateAdminUserProfile`, `updateAdminSettings`, `getAdminHealthTrends` backend.
- Chua test email templates va send test email.
- Chua test doctor schedule route/service integration.
- Chua test destructive admin actions voi audit trail.

## 7. He thong da lam tot

- Admin user list gom du thong tin tu `users`, customer/doctor/staff profile va related data.
- Customer spend chi tinh invoice da `PAID`, tranh cong doanh thu chua thu vao tong chi tieu cua customer.
- Doctor rating duoc tong hop tu ratings va lam tron 1 chu so.
- Service summary tinh bookings va revenue tu appointment services.
- Service status update co validation truoc khi cham database.
- Appointment list map dung status domain (`CONFIRMED` -> `scheduled`, `COMPLETED` -> `completed`) va tinh amount tu appointment services.
- Cancel appointment release doctor schedule slot ve `AVAILABLE`.
- Dashboard tong hop duoc users, services, appointments, revenue, cages va occupied boarding rooms.
- Reports tinh revenue, top services, appointment stats va completion rate theo nhan su.
- Frontend admin service dung query trim, encoded id, method va body cho cac endpoint quan trong.

# Phase 05 Doctor Operations Testing

Phase 5 tap trung vao doctor operations: danh sach lich kham cua bac si, luu nhap phieu kham, hoan tat phieu kham, notifications va frontend API contract cho service orders chuyen khoa. Day la nhom flow quan trong vi bac si la vai tro tao medical visit, prescription, invoice item va dong trang thai lich kham.

## 1. Pham vi

Chuc nang da kiem thu:

- Doctor portal appointment list: map appointment row thanh card/schedule row, tinh summary va room metadata.
- Guard doctor profile: chan load portal khi user chua lien ket voi doctor profile.
- Exam draft: chi cho luu phieu kham khi appointment dang `IN_PROGRESS`.
- Exam draft: luu symptoms, clinical note va prescription theo medical visit.
- Exam completion: chuyen appointment sang `COMPLETED`, tao invoice line, complete appointment service va dong schedule slot sang `DONE`.
- Frontend doctor appointment API: fetch appointments, fallback summary/meta, auth header.
- Frontend doctor notifications: fetch, mark one read, mark all read.
- Frontend doctor exam API: start exam, fetch exam detail, save draft, complete with record.
- Frontend urgent alert va specialist service orders: list services, list orders, create order, cancel order.
- Frontend doctor API reject truoc khi fetch neu khong co auth session.

Ngoai pham vi Phase 5:

- Chua test route-level doctor API bang Supertest.
- Chua test UI component cua doctor portal/exam screen bang React Testing Library.
- Chua test follow-up appointment creation thanh cong khi bac si hen tai kham.
- Chua test conflict follow-up slot va race condition khi slot vua bi dat.
- Chua test invoice da `PAID` va update invoice item cu.
- Chua test specialist service order backend route/service chi tiet.
- Chua test full Prisma integration voi database test that.

## 3. Quy tac AAA

Tat ca test Phase 5 dung AAA.

Backend example:

```js
test("completes exam, creates invoice line and closes the schedule slot", async () => {
  // Arrange
  const tx = createTx();
  mockPrismaTx(tx);

  // Act
  const result = await completeDoctorExam({
    appointmentId: prismaExamAppointment.id,
    doctorId,
    record: doctorExamRecord,
  });

  // Assert
  expect(result).toEqual({ followUpAppointment: null });
  expect(tx.appointment.updateMany).toHaveBeenCalledWith({
    where: { id: prismaExamAppointment.id, doctorId, status: "IN_PROGRESS" },
    data: { status: "COMPLETED" },
  });
});
```

Frontend example:

```ts
test("fetches exam detail and sends draft/complete record payloads", async () => {
  // Arrange
  mockFetchJson({ ok: true, detail: mockDoctorExamDetail, message: "saved" });

  // Act
  const detail = await doctorAppointmentsService.fetchExamDetail(502);
  const draftMessage = await doctorAppointmentsService.saveExamDraft(502, mockDoctorExamRecord);

  // Assert
  expect(detail).toEqual(mockDoctorExamDetail);
  expect(draftMessage).toBe("saved");
});
```

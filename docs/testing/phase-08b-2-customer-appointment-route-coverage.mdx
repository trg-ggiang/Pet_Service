# Phase 08B-2 Customer Appointment Route Coverage

Phase 8B-2 tiep tuc sau Phase 8B. Muc tieu la kiem thu route-level cho customer appointment flow bang Supertest, dam bao Express route, auth context, role guard, request mapping va response/error mapping hoat dong dung truoc khi service duoc goi.

## 1. Pham vi

Chuc nang da kiem thu:

- `GET /api/customer/appointment-options` goi `listCustomerAppointmentOptions` voi `customerId` tu auth context.
- `POST /api/customer/appointment-provider-options` chuyen body va `customerId` vao provider lookup service.
- `GET /api/customer/appointments` chuyen query filter va pagination vao `listCustomerAppointmentsView`.
- `POST /api/customer/appointments` tao appointment va tra ve HTTP `201`.
- `PATCH /api/customer/appointments/:appointmentId/confirm` chuyen appointment id vao confirm service.
- `PATCH /api/customer/appointments/:appointmentId/reschedule` chuyen appointment id, body va `customerId` vao reschedule service.
- `PATCH /api/customer/appointments/:appointmentId/cancel` chuyen appointment id, body va `customerId` vao cancel service.
- Route error mapping: service error co `statusCode` duoc map thanh HTTP status va `{ ok: false, message }`.
- Role guard: user khong phai `customer` bi chan `403` truoc khi goi appointment service.

Ngoai pham vi Phase 8B-2:

- Chua dung JWT signing/verifying that; auth middleware duoc mock de tap trung route contract.
- Chua goi Supabase/DB that.
- Chua test tat ca customer route khac trong `customerPetsRoutes.js`.
- Chua test DB concurrency cho duplicate doctor slot.
- Chua test UI modal booking/reschedule/cancel.

## 3. Quy tac AAA

Tat ca test Phase 8B-2 theo AAA.

Example:

```js
test("POST /api/customer/appointments creates an appointment and returns 201", async () => {
  // Arrange
  createCustomerAppointment.mockResolvedValueOnce(appointment);

  // Act
  const response = await request(app)
    .post("/api/customer/appointments")
    .send(input);

  // Assert
  expect(response.status).toBe(201);
  expect(response.body).toEqual({ ok: true, appointment });
  expect(createCustomerAppointment).toHaveBeenCalledWith(input, customerId);
});
```

## 7. He thong da lam tot

- Appointment routes lay `customerId` tu auth context, khong tin vao client body.
- Create route tra dung `201` khi tao appointment thanh cong.
- List route giu nguyen filter/pagination tu query string de service xu ly.
- Confirm/reschedule/cancel routes truyen dung appointment id path param.
- Reschedule/cancel routes truyen dung body reason/date/time vao service.
- Error tu service duoc route map dung theo `statusCode`, giup UI nhan dung conflict/validation status.
- Role guard chan non-customer truoc khi service appointment duoc goi.

## 8. Khuyet diem va rui ro con lai

- Route test chua cham Supabase/DB, nen chua bat duoc loi schema/RLS/concurrency.

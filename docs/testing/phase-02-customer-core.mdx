# Phase 02 Customer Core Testing

Phase 2 tap trung vao cac chuc nang cot loi cua customer portal: ho so khach hang, ho so thu cung, thong bao va lich su dich vu. Day la nhom feature co rui ro cao ve quyen so huu du lieu, validation input va mapping du lieu hien thi.

## 1. Pham vi

Chuc nang da kiem thu:

- Customer profile: xem profile, update cac truong cho phep, bo qua email input, validate ten rong va ngay sinh tuong lai.
- Customer pets: tao pet, normalize optional fields, validate customer id, validate ten pet, chan xem/sua pet khong thuoc customer.
- Customer notifications: list notifications, tinh unread summary, mark read, mark all read, dismiss, chan thao tac notification khong thuoc user.
- Customer service history: empty state khi khong co pet, build history tu invoice/appointment/item/medical visit, filter type, reject missing customer id.
- Frontend API clients: customer pets, profile, notifications va service history goi dung endpoint, method, auth header, payload va query string.

Ngoai pham vi Phase 2:

- Chua test UI component customer portal bang React Testing Library.
- Chua test route-level customer endpoints bang Supertest cho toan bo customer core.
- Chua test full dashboard pet summary voi vaccination/latest visit do service nay con nhieu nhánh format va aggregation.
- Chua test PDF invoice download vi can mock Blob, object URL va DOM click flow rieng.

## 3. Quy tac AAA

Tat ca test Phase 2 dung AAA.

Backend ownership example:

```js
test("rejects viewing a pet owned by another customer", async () => {
  // Arrange
  supabase.from
    .mockReturnValueOnce(createSupabaseQuery({ data: petRow, error: null }))
    .mockReturnValueOnce(
      createSupabaseQuery({ data: [], error: null }, { resolveMethods: ["order"] }),
    );

  // Act
  const action = () => getPetDetail(petRow.id, 999);

  // Assert
  await expect(action()).rejects.toThrow();
});
```

Frontend API example:

```ts
test("adds a type filter when a specific history type is requested", async () => {
  // Arrange
  mockFetchJson({ ok: true, ...mockServiceHistoryPayload });

  // Act
  await fetchCustomerServiceHistory({ type: "medical" });

  // Assert
  expect(fetch).toHaveBeenCalledWith(
    "http://localhost:5050/api/customer/service-history?type=medical",
    expect.objectContaining({
      headers: expect.objectContaining({
        Authorization: `Bearer ${mockAuthSession.token}`,
      }),
    }),
  );
});
```

## 7. He thong da lam tot

- Customer profile chi update cac truong duoc phep; email van la read-only tu bang user.
- Validation profile chan full name rong va ngay sinh tuong lai truoc khi query database.
- Pet create/update rang buoc theo `customer_id`, giup giam rui ro sua pet cua nguoi khac.
- Optional pet fields duoc normalize ve `null`, tranh luu cac gia tri nhu `none`, `khong co`, chuoi rong.
- Notification mutations luon filter theo `user_id`, han che thao tac tren notification cua user khac.
- Service history build duoc record tu nhieu nguon: pet, appointment, invoice, invoice item va medical visit.
- Frontend customer APIs gui auth header va dung method/query string cho cac thao tac doc, tao, sua, mark read, delete.

## 8. Khuyet diem va rui ro con lai

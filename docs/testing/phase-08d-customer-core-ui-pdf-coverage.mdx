# Phase 08D Customer Core UI And PDF Coverage

Phase 8D tiep tuc follow-up cua Phase 2. Muc tieu la cai thien customer core coverage cho pet dashboard/detail aggregation va invoice PDF download flow.

## 1. Pham vi

Chuc nang da kiem thu:

- Pet dashboard summary map species, breed, latest vaccination va latest medical visit.
- Pet dashboard lay `latestMedicalVisit` tu `medical_visits` that theo appointment ids.
- Pet detail gom invoice items theo tung invoice.
- Frontend invoice PDF download goi dung endpoint va auth header.
- PDF filename doc tu `Content-Disposition` UTF-8 header.
- Latest invoice PDF dung fallback endpoint.
- Matching invoice PDF encode query params.
- PDF download failure tra readable error message.

Ngoai pham vi Phase 8D:

- Chua render React component customer pet dashboard/modal bang Testing Library.
- Chua parse noi dung binary PDF.
- Chua test browser E2E download thuc te.
- Chua test Supabase Storage/image upload trong customer pet UI.

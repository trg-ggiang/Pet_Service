# Phase 08B-3 Customer Appointment Concurrency

Phase 8B-3 tap trung vao rui ro hai request cung dat mot doctor slot. Muc tieu la xac minh slot reservation co guard theo trang thai `AVAILABLE` va customer appointment creation se reject request thu hai khi slot vua bi request khac dat mat.

## 1. Pham vi

Chuc nang da kiem thu:

- `doctorScheduleService.reserveDoctorScheduleSlot` update slot sang `BOOKED` voi dieu kien `id` va `status = AVAILABLE`.
- Hai request cung reserve mot slot: request dau tien thanh cong, request thu hai nhan `null`.
- Slot sau khi request dau tien thanh cong chuyen sang `BOOKED`.
- `customerAppointmentsService.createCustomerAppointment` reject khi `reserveDoctorScheduleSlot` tra `null`.
- Khi reserve slot that bai, appointment service khong insert appointment va khong gui email confirmation.
- `buildScheduleSlots` tao cac slot 30 phut tu work window cua bac si.

Ngoai pham vi Phase 8B-3:

- Chua dung database PostgreSQL/Supabase test that.
- Chua test unique constraint cua `appointments.doctor_schedule_slot_id` bang DB integration.
- Chua test hai HTTP request thuc su song song qua Supertest voi DB.
- Chua test retry/backoff hoac user-facing recovery UI khi gap slot conflict.

## 3. Quy tac AAA

Tat ca test Phase 8B-3 theo AAA.

Example:

```js
test("allows only one reservation when two requests target the same available slot", async () => {
  // Arrange
  const slotState = { id: 400, status: "AVAILABLE" };

  // Act
  const [firstReservation, secondReservation] = await Promise.all([
    reserveDoctorScheduleSlot(slotState.id),
    reserveDoctorScheduleSlot(slotState.id),
  ]);

  // Assert
  expect(firstReservation).toEqual({ id: slotState.id });
  expect(secondReservation).toBeNull();
  expect(slotState.status).toBe("BOOKED");
});
```

## 7. He thong da lam tot

- Slot reservation khong chi update theo `id`; no con bat buoc `status = AVAILABLE`, day la guard quan trong de tranh double booking.
- Khi mot request da doi slot sang `BOOKED`, request tiep theo cho cung slot nhan `null` thay vi thanh cong gia.
- Appointment creation hieu `null` tu reservation nhu mot conflict va tra error `409`.
- Khi slot conflict, flow dung truoc khi insert appointment, appointment service va email confirmation.
- Slot 30 phut duoc tao tu work window, giup unique booking nam tren concrete slot thay vi ca work window dai.

- Chua test transaction rollback voi appointment insert loi sau khi reserve thanh cong.
- Chua co Supertest song song goi route create appointment voi DB test.
- Chua co UI test cho thong bao slot vua bi dat mat va flow chon slot khac.

# Phase 01 Auth Testing

Phase 1 tap trung vao xac thuc va phan quyen, vi day la lop bao ve truoc khi nguoi dung truy cap cac flow quan trong nhu dat lich, kham benh, grooming, boarding, thanh toan va quan tri.

## 1. Pham vi

Chuc nang da kiem thu:

- Dang nhap bang email va mat khau.
- Tu choi dang nhap khi thieu input, tai khoan bi khoa hoac sai mat khau.
- Dang ky tai khoan customer moi.
- Tu choi email trung va mat khau yeu.
- Middleware xac thuc Bearer token.
- Kiem tra `auth_version` de vo hieu hoa phien cu.
- Role guard bang `requireRole`.
- Role context cho customer, doctor, staff va admin.
- Password reset backend: request code, verify code, reset password va tang `auth_version`.
- Auth route Express: login, register, `/me`, forgot-password request/verify/reset.
- Luu, khoi phuc va xoa session o frontend.
- Frontend auth service goi dung endpoint login, register, restore session va forgot password.
- Frontend auth failure: login that bai khong luu session, restore khi khong co session khong goi API.

Ngoai pham vi Phase 1:

- Chua kiem thu UI form login/register/forgot password bang React Testing Library.
- Chua kiem thu JWT that voi `jsonwebtoken`; Phase nay mock `signAuthToken` va `verifyAuthToken` de co lap service/middleware logic.
- Chua kiem thu SMTP production failure va rollback khi tao customer profile that bai.

## 3. Quy tac AAA

Tat ca test moi deu theo cau truc AAA.

Backend service:

```js
test("returns a signed customer session when credentials are valid", async () => {
  // Arrange
  supabase.from
    .mockReturnValueOnce(createSupabaseQuery({ data: activeCustomerUser, error: null }))
    .mockReturnValueOnce(createSupabaseQuery({ data: customerProfile, error: null }));

  // Act
  const result = await loginWithCredentials(" CUSTOMER@example.test ", "PetService@123");

  // Assert
  expect(result).toEqual({
    token: "signed-test-token",
    user: expect.objectContaining({
      role: "customer",
      customerId: customerProfile.id,
    }),
  });
});
```

Frontend service:

```ts
test("restoreSession clears storage when the server rejects the token", async () => {
  // Arrange
  writeStorage(localStorage, mockAuthSession);
  mockFetchJson({ ok: false, message: "Unauthorized" }, false, 401);

  // Act
  const session = await restoreSession();

  // Assert
  expect(session).toBeNull();
  expect(getStoredSession()).toBeNull();
});
```

## 7. He thong da lam tot

- Login chuan hoa email truoc khi query, giup tranh loi do khoang trang hoac chu hoa/chu thuong.
- Tai khoan khong `ACTIVE` bi chan truoc khi tao token.
- Sai mat khau khong tao token.
- Dang ky customer kiem tra email trung va mat khau yeu truoc khi tao user.
- Middleware bat buoc Bearer token va tu choi token thieu hoac sai `sub`.
- Middleware kiem tra `auth_version`, vi vay token cu co the bi vo hieu hoa sau reset password hoac thay doi phien.
- Backend password reset tang `auth_version`, giup vo hieu hoa token cu sau khi doi mat khau.
- `requireRole` chan role khong phu hop bang HTTP 403.
- Auth routes tra status code phu hop cho login/register/forgot-password flow.
- Doctor/staff/admin auth context duoc map dung theo role va profile tuong ung.
- Frontend tach ro session nho lau o `localStorage` va session tam o `sessionStorage`.
- Khi `/api/auth/me` bi server tu choi, frontend tu xoa session cu de tranh trang thai dang nhap gia.

## 8. Khuyet diem va rui ro con lai

- Backend `authService.js` van con nhanh chua duoc test: SMTP production failure, database error branches va rollback khi tao customer profile loi.
- Chua co component test cho Login/Register/Forgot Password UI, nen chua chung minh loi form hien thi dung voi nguoi dung.
- Mot so thong bao loi tieng Viet trong source hien bi loi encoding; test Phase 1 tranh assert nguyen chuoi day du de khong khoa test vao noi dung bi mojibake.
- Coverage backend tong the van thap vi Phase 1 chi tap trung auth, trong khi coverage config dang do toan bo backend source.
- JWT signing/verifying that chua duoc kiem thu trong Phase 1 vi unit test dang mock JWT de co lap service/middleware.

# Phase 07 Cross Feature Critical Flows Testing

Phase 7 la phase cuoi cua strategy hien tai. Muc tieu la kiem tra cac luong critical lien vai tro thay vi chi kiem tra tung service rieng le. Phase nay dung integration nhe voi mocked DB/API de xac minh contract giua customer, staff, doctor, payment va customer history.

## 1. Pham vi

Chuc nang da kiem thu:

- Medical flow backend: staff confirm appointment, staff check-in, doctor complete exam, staff mark payment paid, customer xem service history.
- Medical flow backend: appointment di qua cac trang thai `PENDING` -> `CONFIRMED` -> `IN_PROGRESS` -> `COMPLETED`.
- Medical flow backend: doctor completion tao medical visit, prescription, invoice item va dong schedule slot.
- Medical flow backend: payment confirmation chuyen invoice sang `PAID` va gui email confirmation.
- Medical flow backend: customer service history doc lai dung appointment, invoice, medical visit va prescription.
- Grooming flow backend: complete grooming update grooming/service/appointment thanh `COMPLETED`.
- Grooming flow backend: invoice item da ton tai thi update lai, giam rui ro duplicate invoice item.
- Boarding flow backend: check-in chuyen boarding, cage va appointment sang trang thai dang thuc hien.
- Boarding flow backend: checkout tao invoice items, chuyen boarding `CHECKED_OUT`, cage `CLEANING`, appointment `COMPLETED`.
- Frontend journey contract: customer appointment API, staff operations API, doctor exam API, payment API, customer service history API.
- Frontend grooming/boarding/reschedule/cancel journey endpoints.

Ngoai pham vi Phase 7:

- Chua chay Playwright E2E tren browser that.
- Chua chay voi database test that hoac transaction rollback that.
- Chua xac minh UI rendering, modal validation, loading/error states.
- Chua test real-time/concurrent booking cung slot.
- Chua test PDF invoice render/download thuc te.
- Chua test email delivery thuc te.
- Chua test file upload boarding photo thuc te voi Supabase Storage.

## 3. Quy tac AAA

Tat ca test Phase 7 dung AAA. Do day la flow lien vai tro, moi test co Arrange lon hon cac unit test truoc do, nhung van giu cau truc ro rang.

Backend example:

```js
test("runs the medical flow contract across staff, doctor, payment and customer history services", async () => {
  // Arrange
  const confirmUpdate = createSupabaseQuery({ data: null, error: null });
  const doctorTx = createDoctorTx();
  mockPrismaTx(doctorTx);

  // Act
  await confirmAppointment(appointmentId, staffId);
  await checkInAppointment(appointmentId, staffId);
  await completeDoctorExam({ appointmentId, doctorId, record });
  await markPaymentPaid(invoiceId, "cash");
  const history = await listCustomerServiceHistoryView(customerId, { type: "medical" });

  // Assert
  expect(confirmUpdate.update).toHaveBeenCalledWith(expect.objectContaining({ status: "CONFIRMED" }));
  expect(history.history[0]).toEqual(expect.objectContaining({ status: "completed" }));
});
```

Frontend example:

```ts
test("keeps the medical journey API contract across customer, staff, doctor and history clients", async () => {
  // Arrange
  mockFetchJson({ ok: true, message: "ok", history: [], summary: { total: 1, filtered: 1 } });

  // Act
  await createCustomerAppointment(input);
  await staffAppointmentsService.confirmAppointment(30);
  await doctorAppointmentsService.completeExamWithRecord(30, record);

  // Assert
  expect(fetch).toHaveBeenCalledWith(
    "http://localhost:5050/api/doctor/appointments/30/exam-complete",
    expect.objectContaining({ method: "PUT" }),
  );
});
```

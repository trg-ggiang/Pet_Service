# Phase 08C Route Authorization Coverage

Phase 8C tap trung vao route authorization theo role. Muc tieu la dam bao cac route customer/staff/doctor/admin chi cho role phu hop di qua, va role sai bi chan `403` truoc khi service layer duoc goi.

## 1. Pham vi

Chuc nang da kiem thu:

- Customer role duoc truy cap `GET /api/customer/appointments`.
- Staff role bi chan khi truy cap customer-only route.
- Staff role duoc truy cap `GET /api/staff/appointments`.
- Customer role bi chan khi truy cap staff-only route.
- Doctor role co `doctorId` duoc truy cap `GET /api/doctor/appointments`.
- Admin role bi chan khi truy cap doctor-only route.
- Admin role duoc truy cap `GET /api/admin/dashboard`.
- Doctor role bi chan khi truy cap admin-only route.
- Cac forbidden cases khong goi service layer.

Ngoai pham vi Phase 8C:

- Auth middleware duoc mock de tap trung route role guard, chua dung JWT signing/verifying that.
- Chua test moi endpoint trong tung route file.
- Chua test database RLS/cross-role data leak voi DB test.
- Chua test frontend route guard/UI navigation.

## 3. Quy tac AAA

Tat ca test Phase 8C theo AAA.

Example:

```js
test("blocks doctor users from admin-only dashboard routes", async () => {
  // Arrange
  setAuthUser("doctor", { doctorId: 30 });

  // Act
  const response = await request(app).get("/api/admin/dashboard");

  // Assert
  expect(response.status).toBe(403);
  expect(response.body).toEqual(expect.objectContaining({ ok: false }));
  expect(getAdminDashboard).not.toHaveBeenCalled();
});
```

## 7. He thong da lam tot

- Role guard dung chung `requireRole` chan role sai truoc khi service layer chay.
- Customer/staff/doctor/admin route group deu co representative route duoc test allow va deny.
- Forbidden response tra HTTP `403` va `{ ok: false }`.
- Happy path route mapping van truyen dung domain id tu auth context: `customerId`, `staffId`, `doctorId`.
- Admin dashboard khong cho doctor role truy cap.

## 8. Khuyet diem va rui ro con lai

- Phase 8C chua test JWT real signing/verifying o route group vi auth middleware duoc mock.
- Chua test moi endpoint trong staff/doctor/admin route file.
- Chua test DB-level RLS hoac cross-role data leak.
- Chua test frontend navigation guard khi user doi role/session het han.
- `doctorAppointmentRoutes.js` va `staffRoutes.js` van co route file coverage thap vi file rat lon va Phase 8C chi cover role boundary.

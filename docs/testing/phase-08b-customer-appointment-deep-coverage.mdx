# Phase 08B Customer Appointment Deep Coverage

Phase 8B la phase mo rong sau Phase 3. Muc tieu la dong cac follow-up rui ro cao cua customer appointment flow: provider slot, create appointment thanh cong, doctor slot reservation, rollback khi tao service link loi, pending reschedule va pending cancel.

## 1. Pham vi

Chuc nang da kiem thu them:

- List provider cho medical service: tra ve doctor co slot kha dung, phong, schedule id va service type.
- Create medical appointment thanh cong: validate pet ownership, reserve doctor slot, insert appointment, insert appointment service, gui email va reload appointment.
- Create medical appointment rollback: khi insert `appointment_services` loi, xoa appointment vua tao va release doctor slot ve `AVAILABLE`.
- Pending reschedule: reserve slot moi, update requested date/time, release slot cu va notify doctor.
- Pending cancel: update status `CANCELLED`, release doctor slot va notify doctor.

Phan da ke thua tu Phase 3:

- Appointment options va service filtering.
- Empty appointment view khi customer chua co pet.
- Provider lookup guard khi thieu customer id.
- Create validation cho missing pet va pet ownership.
- Confirm/cancel/reschedule status guards.
- Confirm pending appointment notify doctor.
- Frontend customer appointment API contract tests.

Ngoai pham vi Phase 8B:

- Chua test concurrent booking cung doctor slot voi database test rieng.
- Chua co Supertest route tests cho `/api/customer/appointments`.
- Chua co React component tests cho booking/reschedule/cancel modals.
- Chua test CONFIRMED reschedule/cancel request approval path o route/staff integration level.

## 3. Quy tac AAA

Tat ca test Phase 8B theo AAA.

Example rollback:

```js
test("rolls back appointment and doctor slot when service link creation fails", async () => {
  // Arrange
  ensureDoctorScheduleSlot.mockResolvedValue({
    id: pendingAppointment.doctor_schedule_slot_id,
    doctor_id: pendingAppointment.doctor_id,
  });
  reserveDoctorScheduleSlot.mockResolvedValue({ id: pendingAppointment.doctor_schedule_slot_id });

  // Act
  const action = () => createCustomerAppointment(input, appointmentCustomerId);

  // Assert
  await expect(action()).rejects.toThrow("service insert failed");
  expect(appointmentDelete.delete).toHaveBeenCalled();
  expect(setDoctorScheduleSlotStatus).toHaveBeenCalledWith(
    pendingAppointment.doctor_schedule_slot_id,
    "AVAILABLE",
  );
});
```

Example pending reschedule:

```js
test("reschedules a pending medical appointment, reserves the new slot and releases the old slot", async () => {
  // Arrange
  ensureDoctorScheduleSlot.mockResolvedValue(newSlot);
  reserveDoctorScheduleSlot.mockResolvedValue(newSlot);

  // Act
  const appointment = await rescheduleCustomerAppointment(appointmentCode, input, appointmentCustomerId);

  // Assert
  expect(reserveDoctorScheduleSlot).toHaveBeenCalledWith(newSlot.id);
  expect(setDoctorScheduleSlotStatus).toHaveBeenCalledWith(oldSlotId, "AVAILABLE");
  expect(appointment).toEqual(expect.objectContaining({ time: "10:00" }));
});
```

## 7. He thong da lam tot

- Provider lookup cho medical appointment co the tra ve doctor theo slot cu the, khong chi theo doctor id chung chung.
- Create appointment dong bo duoc `appointments`, `appointment_services`, doctor slot va email confirmation.

- Pending reschedule co reserve slot moi truoc khi release slot cu, giup tranh mat lich neu slot moi khong kha dung.
- Pending cancel release doctor slot va notify doctor, giup slot quay lai pool booking.
- Appointment mapper sau create/reschedule/cancel van tra ve du lieu hien thi co pet, doctor, room, service fee va status.
